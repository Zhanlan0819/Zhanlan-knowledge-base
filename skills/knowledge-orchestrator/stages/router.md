# 内部阶段：内容分流

目标：把 RAW 按真实未来用途拆成资产，同时保留来源身份和风险边界。只处理当前 router 阶段。

## 核心规则

- 必须覆盖 RAW 中全部非空白内容；不能静默漏掉段落。
- 资产类型只使用 Schema 允许的 8 类：知识内容、项目案例、文案素材、观点灵感、待办行动、项目方案、外部资料、待整理。
- 不确定去向时进入“待整理”，不要猜。
- 外部资料 / 项目案例 / 项目方案表示来源或载体身份，不是知识加工终点。
- 如果这些材料里存在可复用判断、原则、步骤、方法或案例结构：保留原来源资产，同时对可复用的具体原文片段额外建立 knowledge 资产；允许锚点重叠。
- 不要把整份外部材料直接改成知识，只抽取真正可复用片段。
- 敏感来源、高风险判断、无法确认的路由使用 risk_flags；不要自行消除风险。
- 用户已有 `user_brief` 时，分流必须服务本轮整理目标，但不得为了迎合目标而伪造知识资产。

## 用户审核原则

正常分流项无需逐条让用户确认。只有待整理、风险、明显误分流或来源边界问题值得进入用户审核。
