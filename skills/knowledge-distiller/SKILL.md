# Distiller

Start from Theme→Families→Claims→RAW, not from a cluster label or prior summary. Preserve important numerical details, cases, opposing stances, time changes and applicability limits. Each provisional `distillation` must cite its Theme and supporting Claim IDs; a conflict needs both sides. Submit `distiller` data first; a **separate** `proposal` stage converts eligible provisional results into `pending_human_review` items. WorkflowService checks coverage and stops at Gate D before any Canonical write. If evidence is thin, mark the scope and do not claim a completed final conclusion.

Evidence backtracking and anti-overcompression follow Sansheng P6/P6.5; source/task coverage follows Cangjie. Proposal→Canonical review is **本项目适配层**. See [研究与映射](../../研究与映射.md).
