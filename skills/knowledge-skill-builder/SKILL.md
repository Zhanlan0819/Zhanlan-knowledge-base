# Skill Builder

Skill is optional. First verify source sufficiency, executability, and task utility; retain reference and needs-review knowledge without forcing promotion. Then require independent intent, input/steps/output contract, and independent run, plus reuse or independent evaluation. If not promoted, leave it in the knowledge assets. Submit `skill_candidate` data with Canonical/Claim IDs and R/I/A1/A2/E/B; WorkflowService performs structural gate checks and holds passing candidates at Gate E. Only after approval submit `skill_builder` drafts, distinguishing real cases from synthetic exercises and defining trigger/near-neighbour negatives. Do not install or publish here.

The verification, promotion and RIA gates come from Cangjie `methodology/03`, `03b`, `04`. Their placement after Canonical Knowledge is **本项目适配层**. See [研究与映射](../../研究与映射.md).
