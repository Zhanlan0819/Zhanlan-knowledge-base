# Router

Preserve the exact input as RAW before interpretation. Split by meaning, not by paragraph or one whole-note label; one quote may support more than one asset only when the meanings genuinely differ. Every part must point to an exact RAW quote; ambiguous repeats need an occurrence index. Cover the whole nonblank RAW: uncertain segments go to `unorganized`. Assign one asset type per part and parent/child tags as stable navigation. Submit `router` data (`assets` plus explicit `risk_flags`) to WorkflowService; it, not this Skill, decides completed versus Gate A/failed. Do not create Canonical or Skill here.

This multi-asset routing is **本项目适配层**. Its route-first idea is informed by Nuwa Phase 0 and Sansheng's separate pipelines; neither repo implements this eight-type personal-knowledge Router. See [研究与映射](../../研究与映射.md) when explaining provenance.
