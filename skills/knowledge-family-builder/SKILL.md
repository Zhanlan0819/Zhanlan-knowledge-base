# Family Builder

Use high-precision literal pre-grouping, then compare likely neighbours within a theme for **the same assertion**, not merely the same topic. A Claim that is an example, refinement, or contradiction is not automatically a repeat. Preserve all Claim IDs and independent source counts; do not count a reused mother manuscript as separate corroboration. A semantic model may return only ID groups, never rewrite representative Claims. Mark uncertain groups as suggestions for review. Submit `family_builder` data; WorkflowService checks every Claim is linked exactly once and marks descendants stale if this version is withdrawn.

The two-stage Family rule and model-ID-only constraint are documented in Sansheng `creator-craft.md` P5. Applying them across a heterogeneous personal knowledge base is **本项目适配层**. See [研究与映射](../../研究与映射.md).
